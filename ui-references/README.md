# UI 视觉参考索引与分析 (UI References)

本目录存放用户提供的样式参考截图，作为本项目 UI 风格的视觉设计参照。

## 核心原则

- **视觉风格参考**：提取其视觉层级、深色质感、大圆角胶囊系统、排版与状态表达。静态截图不能证明使用了毛玻璃，也不能作为动画实现或实时性承诺的依据。
- **功能逻辑独立**：不照搬参考产品的功能逻辑，严格以本项目自身的功能规格、真实接口契约与已确认的设计为准。
- **按功能对应还原**：相同功能优先对照参考 UI 还原；不同功能保留本项目的能力和操作，延续相同的配色、排版、圆角、留白与状态表达，不为视觉还原增删业务功能。
- **命名规范遵循**：目录与文件名已完全规范为合法 kebab-case（无空格、无特殊符号）。

## 视觉设计方向 (Design Language)

以下色值与尺寸是最初的估测方向，不是从截图获取的精确规格；实际配色以 `src/theme/presets/` 为准，共享几何由 `src/ui/tokens.ts` 转出，不在组件中复制本段的数值。多主题维护见 `docs/themes.md`。

1. **色彩与材质 (Colors & Materials)**
   - **主背景**：纯黑/极深灰沉浸底色（`#000000` ~ `#0d0d0d`）。
   - **容器与药丸**：深灰半透微光感表面（`#1c1c1e` 或 `rgba(255, 255, 255, 0.08)`），选中/高亮态采用 `#2c2c2e`。
   - **品牌/主行动色**：明亮纯净的科技蓝（Vibrant Blue，如 `#007aff` / `#0a84ff`），用于用户气泡与发送/停止按钮。
   - **边框与分隔**：极细或微光边框（`rgba(255, 255, 255, 0.08)`），避免生硬的实线描边。

2. **圆角系统 (Radii System)**
   - **超大圆角与全胶囊 (Full Pill)**：按钮、输入栏、Tab 容器统一为高度一半的完全圆角。
   - **卡片与气泡**：采用 18px ~ 24px 大圆角，视觉柔和自然。
   - **侧栏滑出时主内容视口**：平移同时裁切为 24px ~ 28px 圆角。

3. **微交互与状态表达 (Status & Micro-interactions)**
- 顶栏会话信息区与全屏会话面板共享真实运行状态；活动状态消费真实SSE，过程与步骤按需回读，不因截图变化而宣称所有字段严格实时。
   - 思考态统一呈现为极简的律动圆点气泡或微旋转光圈。

## 本项目的适配取舍

- 保留聊天／任务／目标／应用四个主 Tab；侧栏仍只切换或新建空间，搜索仅过滤已读取列表，不复制参考里的点子、资源库、旁聊与导航排序。
- 会话信息区打开全屏会话面板，动态／审批／工作区／历史四项胶囊 Tab 同层切换；不改为底部 Sheet。
- 任务页的活动历史／定时任务／网页监控同样使用带图标的整组胶囊 Tab；内容区以真实列表的标题、状态、时间为主。筛选、排序、刷新及关键警告保持直接可见，不照搬参考图中并不存在的任务数据。
- 目标页复用整组胶囊、紧凑工具栏和卡片层级，突出全局目标的真实里程碑；状态操作、删除确认、过期数据与结果待核对提示仍直接可达，不套用参考图业务内容。
- 使用原创的本地 Muse 位图头像 `assets/images/muse-companion.png`，打包后离线可用，不裁切参考角色；邀请、分享、头像编辑与语音未接入，不新增虚假操作入口。
- 保留经典蓝白、晨光白与深夜黑，无本机偏好时默认经典蓝白；聊天主屏沿用圆形侧边操作、蓝色用户气泡与轻盈的全胶囊输入区。聊天／任务／目标／应用四个主页面的底部 Tab 均显示图标与标题，使用一致高度并保留无障碍名称，不追求逐像素复制。
- 不复制滚动正文被会话信息区遮挡的效果；顶栏独立占位，原生键盘出现时进入紧凑布局并暂时收起主导航，小屏仍可阅读最新回复。面板切换 Tab 不继承其他 Tab 的滚动偏移。
- 聊天主屏以本地头像、名称和真实状态形成居中会话信息区；正文在其下方独立滚动，不复制参考图的遮挡。空白聊天只保留“有什么想聊的？”短句，不显示营销标题或建议按钮。有内容时用更轻的气泡内边距和适中的宽度；会话面板动态区直接显示真实执行或同步状态，不复制参考图的“今天”、时间和虚构活动。状态口径说明按需展开，失同步、失败、待审批仍直接显示。
- 审批全文不截断、不解释 HTML/Markdown，批准与拒绝均保留二次确认；外观变化不能放宽鉴权、同步与提交结果未明时的禁用约束。
- 各页面只呈现真实业务数据，不填示例内容；能力接入状态以根级项目地图为准，不在视觉参考中维护第二份进度表。应用更新保持独立于业务服务器，仅外观与根级主题统一。
