# 移动开发指南

本文维护导航、状态所有权与协议消费边界。常用命令和高层架构在 [CLAUDE.md](../CLAUDE.md)，项目约束在 [AGENTS.md](../AGENTS.md)，主题和发布分别见 [themes.md](themes.md)、[android-release-guide.md](android-release-guide.md)。源码与测试决定当前实现，历史交接不能替代它们。

## 连接与页面所有权

`AppRoot` 组装主题、安全区、错误边界与独立更新。`WorkspaceScreen` 内的连接根按 workspaceKey 建立 ApiProvider 和业务 Provider；换服释放旧连接状态，切页面、切主题和打开设置不重建连接。

页面使用工作区本地状态，不使用 Expo Router 或 react-navigation：

| 状态/入口 | 职责 |
| --- | --- |
| `messages` /「消息」 | 冷启动会话列表，main 默认会话在首位，其余按更新时间倒序；新建用文字按钮 |
| `chat` | 二级聊天，PNG 形象与标题，点击形象打开会话切换面板；无底栏 |
| `news` | 全局新闻阅读列表；文章和来源管理为二级，无底栏 |
| `settings` | 连接、身份/人设、记忆、全局 Dream、目标、任务、监控、文件、浏览器、短信、会话指令/技能、主题与更新 |

`SessionListScreen` 是目录；`SessionPanel` 仍是当前执行、审批与历史的信息覆盖层，两者不是同一页面。设置不会挂载另一个聊天或销毁已访问会话。所有会话共用一份工作区文件，切聊天不改变文件归属，也不清文件草稿。

底栏只在三个一级根页且无键盘/覆盖层时显示。main 不提供删除入口。删除专题需明确确认 ID 与不可恢复范围；成功后释放该会话所有者、草稿、反馈与维护状态，回消息列表。请求未明先回读，不自动重发。目录失败保留旧记录，不合成默认会话或空列表。

## 覆盖层、返回与键盘

- 根层 KeyboardAvoidingView 是唯一键盘避让层；Android 用 height，iOS 用 padding，composer 不再叠加键盘高度。
- 原生 Sheet/Modal 隔离背景触控与读屏；关闭返回原页面。Back 优先收键盘、关闭浏览器/覆盖层，再逐级退出文章、来源管理、设置子页和聊天；三个根页交还系统。
- PageHeader 是通用固定二级标题/返回栏，不随正文滚动。文件目录、详情、完整保存预览、删除确认、未保存草稿与未明锁按 FilesStore 顺序处理，返回不能绕过保护。
- 浏览器是全屏原生 WebView，以同源一次性票据连接后端 Chrome，不注入 API token；关闭不停止后端 Chrome，换服销毁旧状态。

## 协议消费与恢复

修改前核对当前后端 health / serviceVersion、`/docs`、`/openapi.json` 与服务端 contracts，实际消费本模块相关接口。服务端 Web 的 API/聊天聚合可供参考，但不是另一份契约。跨端任务在同一会话内按契约实现，不能沿用永久只读后端的旧分工。

聊天 AG-UI 是执行流；RuntimeProvider 持有一条 `/api/events` 通知流，领域 Store 按失效与重连回读。`conversation_updated` 是历史失效，不是消息正文或系统推送；不因此重挂载聊天、清空草稿或增加第二条通知流。

写入不默认幂等。超时、断线或结果未明时保留草稿并锁定重提，先回读实际状态，再按端点所需的明确核对解锁，不自动重发。读取失败保留旧值和错误，不伪装空列表；保存前废弃可能迟到的旧 GET。异步结果始终绑定原连接、Session 与请求资格。

连接页测试是可选探测，保存验证当前草稿后才生效；新密钥重新认证，同址空密钥可沿用已有 token。取消探测不落盘，迟到结果不污染草稿。换服明确确认清理旧本地业务缓存与凭据，不删除远端数据；清理失败保留恢复入口。AccessKey 不持久化。

工具卡、审批与活动仅消费服务端实际投影；批准不等于落盘成功。assistant Markdown 用原生组件呈现，HTML 按字面处理，不加载 Markdown 图片，外链仅允许无凭据 HTTP(S)。用户消息原文不改写。

助手聊天正文通过 `src/chat/chat-visible-text.ts` 的同一可见投影决定气泡有无、渲染内容和复制内容：普通正文中的 `<think>` 块在未闭合时也不显示，分片标签不能先漏出再删除；正式正文继续流式展示，不按“思考”“正在”等词删句子。行内/围栏代码里的字面标签保留。原始历史与工具卡不被改写，文件原文、共享 `MarkdownContent` 和完整修改确认不使用这条聊天清理规则。

## 会话与通知

- 公开 `sessionId` 为 main 或服务端创建的 UUID；`piSessionId` 仅表示底层历史绑定。reset 保留公开 ID，完整历史读取后建立新绑定。聊天所有者以公开 ID + epoch 隔离。
- `SessionStore` 只管理目录，`ChatSessionStore` 管理每会话聊天/设置草稿。目录与正文不复制第二份服务端事实。创建无客户端幂等键，结果未明锁住再次创建，先回读核对。
- `/api/events` 唯一通知流使用 `session_status_updated` / `session_presence_updated`，ready 集合为 sessionStatuses / sessionPresences。`conversation_updated` 只失效指定公开会话；piSessionId 变化也需要回读，不能继续旧上下文。
- 来源元数据仅消费服务端的 featureSource，不从正文猜来源。通知续聊只把实际会话与消息引用预填到用户输入框；会话已删除则安全回消息并提示，不另建讨论、不回退另一会话、不自动发送。
- subagent 是无独立会话的模型工具，UI 显示“子任务”，协议字段 subagentId / waiting_subagents 保持不变。

## 新闻与短信

- 新闻阅读列表与反馈按钮是兄弟节点。推荐/全部在筛选菜单，收藏独立筛选；来源与抓取在更多菜单。详情为整页视图，顶栏只保留返回，底部固定讨论与喜欢/不喜欢/收藏，未明回读和讨论错误不能藏进菜单。
- 反应互斥、收藏独立，逐篇写入/未明锁共用 newsActionLocked；不喜欢不自动移除文章。客户端无评论 UI、评论写方法、点击统计或兴趣算法，但仍按契约保留历史评论，不迁移或删除服务端数据。
- 全局 NewsPreferencesStore 在连接层保留明确 notes 草稿，只提交可写偏好，不写 learnedNotes。重开/前台读取保留脏草稿，自动读取不解除未明锁，显式核对后才可再保存。
- RSS 来源管理保留添加草稿与删除确认；默认已有来源在前，添加/预设显式展开，抓取与分析状态在后。来源失败与空列表是不同状态。
- SmsProvider 在连接层持有原生权限、监听和 SmsStore；短信页只在可见且前台时进行有界只读刷新，离页/后台停止。静默结果不依赖聊天通知。偏好 API 是专属指令编辑入口，后台规则所有权由当前服务端确定，不在客户端再建标签或规则库；首轮批量导入与后续增量的类型/状态消费当前契约。
- 新闻讨论先选目标会话，追加标题、限长正文和来源 URL，明确标为不可信外部引用；保留已有草稿，用户可编辑后再发送。打开讨论不调用模型。短信只调用全局 `/api/information` 管线。

## 文件与全局整理

FilesStore 持有唯一扁平工作区的目录、原文、草稿与完整前后确认。首次实际修改才建草稿，正文输入节点不重挂载。HTTP 请求与响应均无 scope/owner，仅 path；`shared/` 是普通相对目录，不是第二根。文件详情菜单保留元信息/下载/删除，写入未明只读核对后由用户明确解锁。

审批 preview 只有 workspace/skill 范围与完整 before/after，来源 sessionId/runId 与子任务观察标识保留，不存在文件 owner。批准不等于实际提交成功，不能弱化版本绑定和逐次人工确认。

Dream 全局设置只有 enabled/prompt；游标按来源会话记录，待决建议保留完整正文和 sourceSessionId。应用前确认实际目标，来源已删不能复活；全局资料影响所有会话。run 与待决项写入结果未明先回读并人工解锁，不自动执行第二次。

## 依赖与验证

依赖和 API 先核对当前 manifest 与相应版本文档，不在指南硬编码下一轮升级名单。原生包用 `npx expo install` 解析配套版本，检查 peer 范围，不用 force 或修改第三方包掩盖冲突。CNG 生成的 android/ios 不手工维护；新增 Expo Go 未包含的模块需要开发构建验证。

代码门禁为 lint/typecheck/test；夹具回归不替代当前真实后端、外部模型与 Android 原生链路。真实验收检查当前源码版本、触控、键盘、安全区、前后台与所改恢复场景。主题按其指南覆盖三主题/窄屏；用户可见行为同步中英文手册。文档-only 检查引用、差异与一致性，不启动业务/模型/原生验收。
