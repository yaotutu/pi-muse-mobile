# 移动开发指南

本文维护导航、状态所有权与协议消费边界。常用命令和高层架构在 [CLAUDE.md](../CLAUDE.md)，项目约束在 [AGENTS.md](../AGENTS.md)，主题和发布分别见 [themes.md](themes.md)、[android-release-guide.md](android-release-guide.md)。源码与测试决定当前实现，历史交接不能替代它们。

## 连接与页面所有权

`AppRoot` 组装主题、安全区、错误边界与独立更新。`WorkspaceScreen` 内的连接根按 workspaceKey 建立 ApiProvider 和业务 Provider；换服释放旧连接状态，切页面、切主题和打开设置不重建连接。

页面使用工作区本地状态，不使用 Expo Router 或 react-navigation：

| 状态/入口 | 职责 |
| --- | --- |
| `group` /「消息」 | 冷启动主视图，群聊和来源通知展示；UI 不叫「全部」，底层 group/Agent/SSE 协议与 ID 不改 |
| `chat` | 独立二级私聊，有明确返回+姓名/状态，无底栏，由 ConversationHost 保留已访问 Agent 的所有者 |
| `news` | 新闻一级根 Tab，直接阅读 NewsPage，独立于聊天 Agent 与旧偏好；文章详情/来源管理为二级无底栏 |
| `discussion` | 按通知引用隔离的来源讨论，不混入普通群或私聊 |
| `agent` | 智能体设置、私有文件、规则、技能、维护与动态入口（从设置→智能体管理进入），二级无底栏 |
| `settings` / `feature` | 设置一级根 Tab，收纳连接/主题/更新/记忆/Dream/默认组配置/智能体管理；子页为二级无底栏 / 扩展设置 |

其他已存在页面类型或数据层不等于当前可见入口；例如目标数据层保留，但不能根据历史底栏截图宣称现在有目标 Tab。

一级导航底栏（`PrimaryTabBar`）仅在三个一级根页（`消息` / `新闻` / `设置`）渲染，键盘展开或处于任何二级页面（私聊、文章详情、新闻源管理、设置子页、智能体设置、通知讨论等）时隐藏底栏。消息群聊顶部为「消息」标题与明确的「成员」按钮（打开 `GroupMemberSheet`，包含服务端全量 Agent 目录搜索过滤，每项区分「在群里 @」与「单独聊」）。头像单击进入独立私聊，标题不点击进设置，移除所有头像长按导航；消息气泡的长按反馈与复制继续保留。无智能体横滑切换。

设置检查对象与当前聊天对象分开，打开设置、动态或审批不切换底层聊天。ConversationHost 隐藏而不卸载运行中的私聊；连接销毁、Agent 删除与会话 epoch 重置分别释放对应所有者。新闻、群和短信各自持续挂载，不因选择另一个头像销毁。

## 覆盖层、返回与键盘

- 根层 KeyboardAvoidingView 负责软键盘避让；Android 用 height，iOS 用 padding，不在 composer 再叠加键盘高度。键盘事件控制头像紧凑态与滚动锚定。
- 全屏会话面板与底层同根持续挂载，屏蔽底层触控与读屏；关闭动画完成前不提前释放。重新打开默认动态，关闭保留页面与返回来源。
- Back 优先键盘/覆盖层，再处理详情、管理页、草稿与二级页面；三个一级根页不消费 Back（返回 `none`）；二级私聊按来源返回原群聊、新闻或通知讨论，通知讨论返回来源聊天；新闻文章返回新闻，新闻源管理返回新闻；设置子页返回设置首页。文件目录、正文、确认与未保存草稿按 FilesStore 的保护路径处理，不能用换 Agent 绕过未明写入。
- 智能体、文件、资料/记忆/Dream 子页使用固定 AgentHeader，返回不随正文滚动，不在领域面板重复持有导航标题。
- 浏览器是全屏原生 WebView，沿当前连接换一次性同源桌面票据；无独立浏览器地址/密码配置，不注入 API token。Back 先收键盘再关闭 viewer，关闭不停止后端 Chrome；重开/显式重试重新取票据，换服销毁旧状态。

## 协议消费与恢复

修改前核对当前后端 health / serviceVersion、`/docs`、`/openapi.json` 与服务端 contracts，实际消费本模块相关接口。服务端 Web 的 API/聊天聚合可供参考，但不是另一份契约。跨端任务在同一会话内按契约实现，不能沿用永久只读后端的旧分工。

聊天 AG-UI 是执行流；RuntimeProvider 持有一条 `/api/events` 通知流，领域 Store 按失效与重连回读。`conversation_updated` 是历史失效，不是消息正文或系统推送；不因此重挂载聊天、清空草稿或增加第二条通知流。

写入不默认幂等。超时、断线或结果未明时保留草稿并锁定重提，先回读实际状态，再按端点所需的明确核对解锁，不自动重发。读取失败保留旧值和错误，不伪装空列表；保存前废弃可能迟到的旧 GET。异步结果始终绑定原连接、Agent/Session 与请求资格。

连接页测试是可选探测，保存验证当前草稿后才生效；新密钥重新认证，同址空密钥可沿用已有 token。取消探测不落盘，迟到结果不污染草稿。换服明确确认清理旧本地业务缓存与凭据，不删除远端数据；清理失败保留恢复入口。AccessKey 不持久化。

工具卡、审批与活动仅消费服务端实际投影；批准不等于落盘成功。assistant Markdown 用原生组件呈现，HTML 按字面处理，不加载 Markdown 图片，外链仅允许无凭据 HTTP(S)。用户消息原文不改写。

助手聊天正文通过 `src/chat/chat-visible-text.ts` 的同一可见投影决定气泡有无、渲染内容和复制内容：普通正文中的 `<think>` 块在未闭合时也不显示，分片标签不能先漏出再删除；正式正文继续流式展示，不按“思考”“正在”等词删句子。行内/围栏代码里的字面标签保留。原始历史与工具卡不被改写，文件原文、共享 `MarkdownContent` 和完整修改确认不使用这条聊天清理规则。

## 群与来源讨论

- `src/group/` 独立持有群输入与流，消息（原群聊）当前为文本输入，不支持附件和消息反馈。显式 @ 优先且只发一个目标；无目标由服务端薄路由判断，普通聊天交默认回复者。
- 模糊/多匹配返回候选与原文，确认前不执行目标。确认以新 ID 和原文显式投递，不清后来输入的新草稿；取消不发送。默认组设置和公开能力由连接级 RoutingSettingsStore 持有，不复制私有指令或自动保存。
- 来源通知只读展示服务端 marker 投影，不能从正文猜来源。继续处理仅传真实承接位置引用，由服务端核实来源 Agent；每条通知的讨论与草稿独立，打开不调用模型，显式发送才运行。
- GroupChat 持续挂载，群/各来源讨论有自己的 GroupComposer。客户端接管提交即清输入，生成期间可准备下一条；回读仅释放原提交，不清后续或其他草稿。断流先核对，原通知失效禁发，不回退 main。
- 隐藏的群所有者仍消费已有 runtime 失效/重连版本；发送期间延迟回读，失败保留旧快照。审批作为原消息/通知讨论上的覆盖层直接打开，关闭后保留原页；来源讨论进私聊按原来源准确返回。

## 新闻与短信

- 新闻阅读列表与反馈按钮是兄弟节点。推荐/全部在筛选菜单，收藏独立筛选；来源与抓取在更多菜单。详情为整页视图，顶栏只保留返回，底部固定讨论与喜欢/不喜欢/收藏，未明回读和讨论错误不能藏进菜单。
- 反应互斥、收藏独立，逐篇写入/未明锁共用 newsActionLocked；不喜欢不自动移除文章。客户端无评论 UI、评论写方法、点击统计或兴趣算法，但仍按契约保留历史评论，不迁移或删除服务端数据。
- NewsPreferencesStore 在连接层保留明确 notes 草稿，只提交可写偏好，不写 learnedNotes。重开/前台读取保留脏草稿，自动读取不解除未明锁，显式核对后才可再保存。
- RSS 来源管理保留添加草稿与删除确认；默认已有来源在前，添加/预设显式展开，抓取与分析状态在后。来源失败与空列表是不同状态。
- SmsProvider 在连接层持有原生权限、监听和 SmsStore；短信页只在可见且前台时进行有界只读刷新，离页/后台停止。静默结果不依赖聊天通知。偏好 API 是专属指令编辑入口，后台规则所有权由当前服务端确定，不在客户端再建标签或规则库；首轮批量导入与后续增量的类型/状态消费当前契约。
- 专用新闻/短信 facade 不传当前聊天 agentId；新闻讨论按 receipt 进入实际承接目标，未明时只核对，不自动重发。

## 文件与 Agent 管理

FilesStore 持有目录、正文、草稿和完整前后确认；首次实际修改才建草稿，输入节点不重挂载，确认不得只展示渲染摘要。文件详情菜单提供元信息/下载/删除，按实际入口逐层返回，切 Agent 前处理未保存状态。

添加 Agent 先由服务端确认持久存在，再打开设置，不用首次聊天冒充创建。创建/删除期间防重复提交，结果未明回读目录；删除确认明确 ID、名称与不可恢复范围，删除非当前 Agent 不切走原聊天。旧创建结果不能进入新连接。

## 依赖与验证

依赖和 API 先核对当前 manifest 与相应版本文档，不在指南硬编码下一轮升级名单。原生包用 `npx expo install` 解析配套版本，检查 peer 范围，不用 force 或修改第三方包掩盖冲突。CNG 生成的 android/ios 不手工维护；新增 Expo Go 未包含的模块需要开发构建验证。

代码门禁为 lint/typecheck/test；夹具回归不替代当前真实后端、外部模型与 Android 原生链路。真实验收检查当前源码版本、触控、键盘、安全区、前后台与所改恢复场景。主题按其指南覆盖三主题/窄屏；用户可见行为同步中英文手册。文档-only 检查引用、差异与一致性，不启动业务/模型/原生验收。
