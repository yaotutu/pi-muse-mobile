# 移动开发指南

本文面向 Pi Muse Mobile 的日常开发任务，整理术语、导航、契约消费、状态保护和验证入口。它不复制业务功能清单、历史验收或完整主题规范；修改前必须静态核对当前源码与相关测试，指南只提供入口和稳定边界。

## 源码入口

- 组装：`src/app/AppRoot.tsx` 只组装 Provider 与唯一 `WorkspaceScreen`；`src/workspace/` 是当前工作区、页面组装和状态挂载入口。
- 连接与协议：`src/connection/`、`src/api/`、`src/chat/`、`src/runtime/` 分别负责连接记录、HTTP/SSE 客户端、聊天聚合与运行状态。迟到响应不得污染当前连接或智能体。
- 业务域按目录划分：`src/agents/`、`src/approvals/`、`src/activities/`、`src/jobs/`、`src/monitors/`、`src/goals/`、`src/memories/`、`src/files/`、`src/profile/`、`src/dream/`、`src/feedback/`、`src/attachments/`、`src/browser/`、`src/update/`。修改任一领域先读对应源码与测试，不在本指南复制字段清单。
- 外观：`src/theme/`、`src/ui/` 与 [主题维护](themes.md) 是唯一主题细节入口；业务页面消费语义颜色与共享 tokens，不散写固定色值或布局魔法值。

## 统一术语与导航

- 「顶栏」指群聊与私聊共用的正常流头像切换区。群聊右侧打开群组信息，私聊右侧打开当前智能体设置；再次点选中头像或长按头像进入主页。动态与审批从主页或设置进入，新闻阅读从新闻主页进入。顶栏占正文以外的高度，键盘打开时缩小头像并隐藏名称；详细状态只在会话动态面板显示。
- 工作区只有根层 `KeyboardAvoidingView` 负责软键盘避让：Android 使用 `height` 收缩聊天正文和输入区的共同容器，iOS 使用 `padding`；不在 composer 上另加键盘高度。键盘事件只控制头像栏紧凑态和滚动锚定。
- 本项目不使用 Expo Router 或 react-navigation。无底部主导航，冷启动 `group`；`group-info` 为群信息，头像栏直接切换群聊与私聊，无列表路由；全局 `settings` 来自群组信息右上角，`chat` 是成员私聊，`agent` 是成员主页与子页，`feature` 是内置成员功能设置，`goals` 不在底栏。新闻属于当前连接，不因导航或会话重置清空。
- 会话面板与聊天同根层持续挂载；展开时屏蔽底层触控和读屏，动态／审批／执行历史平级切换。成员主页、智能体设置和文件、规则、技能、维护子页全屏显示。Back 优先键盘和覆盖层；私聊返回群聊，RSS 返回功能设置再回原成员主页或智能体设置；文件逐层处理确认、草稿、详情和目录。未明写入不能靠返回或换成员绕过，规则/技能草稿按原 Agent 保留。
- 从成员主页或智能体设置打开动态面板只改变覆盖层，不把底层页面切到私聊；重新打开默认选动态，关闭保持原页面及其返回来源。全局资料、记忆与 Dream 由 `SettingsPage` 在滚动区外共用 `AgentHeader`，领域面板不再持有返回入口或重复页标题；返回不变更各 Store 的草稿和写入资格。
- `ConversationHost` 保留当前连接中已访问智能体的聊天所有者；切换智能体只隐藏旧视图，不卸载仍在运行的 SSE。智能体删除、会话 epoch 重置与连接销毁分别释放对应所有者；其他主页面只渲染一次。每个所有者以自己的 runtime、session 与失效版本回读，隐藏后返回前台时按原跟随状态定位滚动。
- 设置页中的浏览器是全屏原生 WebView，沿用当前服务器连接换取一次性桌面票据，不增加独立地址或密码配置。打开时底层页面保留挂载但屏蔽触控与读屏，主导航隐藏；Back 先收键盘，再关闭 viewer，不操作服务端 Chrome。票据仅留连接内存，不向 WebView 注入 API 凭据；关闭清理票据，重开和显式重试重新获取，换服销毁整个连接内的 store。导航边界与服务端桌面网关共同验收。
- `AgentAvatarStrip` 替代独立会话列表，群聊在最前、内置智能体次之，其余按 ID 稳定排序，不随活跃时间变化。点击切换，选中头像再次点击或长按进入主页；群聊动作进入群组信息，私聊动作进入当前智能体设置。全局设置与添加智能体位于群组信息。`profileReturn` 记录群聊/群信息/私聊入口；新闻从主页进入并逐层返回。`ChatSwipeArea` 仅观察消息阅读区的快速单指横扫，不获取 responder，输入栏/二级页面不参与；代码和表格阻止起手冒泡，保留横滚。所有切换共用 `changeAgent` 文件草稿保护。切换不重挂载会话所有者、不取消运行、不复用草稿；头像栏自动露出选中目标。
- 添加成员先通过 `POST /api/agents` 确认真实智能体，成功后才选择并进入主页，不保留本地临时成员双轨。空成员无需第一条消息即可跨重启出现，并参与群成员、定向和通知绑定；响应未明只回读原 ID，手动再次添加仍确认同一 ID，不重置已有智能体。换连接时取消在途创建，迟到响应不得选择新连接的智能体。
- 旧 `AppShell`、旧 Screen/Sheet 和产品演示分支已删除，不恢复双界面入口；`src/ui/Sheet` 仅服务独立应用更新流程。

## 契约与状态

- 按模块串行推进。开始实现前核对当前真实后端的 `/docs`、`/openapi.json` 与 health 版本，并由实际客户端重跑本模块相关真实接口与安全主线；只看 schema、打开文档或沿用历史通过不算预验。缺少契约、凭据或合法场景时先报告，本模块实现与验收未收口前不进入下一个新模块；开工预验不替代收口验收。
- 修改 HTTP/SSE 前核对当前服务端 `/docs`、`/openapi.json`、health 版本与 `pi-muse-server/src/http/contracts/`；服务端自有 `web/src/lib/api.ts` 与 `web/src/chat/chat-state.ts` 可作为分帧和 AG-UI 聚合参考，但不是契约权威。
- 聊天 AG-UI SSE 与 `/api/events` 通知 SSE 是两条流；运行、审批、活动与通知落盘后的历史失效共用一条通知流。`conversation_updated` 触发对应会话的权威历史回读及群功能通知快照/列表摘要同步，重连后同样回读；不等于系统推送，不重挂载聊天或清空草稿。具体字段、事件顺序和错误语义以当前契约为准，不从历史交接或旧客户端代码推测。
- 用户消息原文展示；assistant Markdown 用原生组件绘制，HTML 按字面文字处理且 Markdown 图片不加载。消息与搜索来源链接仅允许无凭据 HTTP(S)，不推断隐藏工具详情或审批事实。
- 不假定写操作幂等。请求超时、断线或结果未明时保留草稿并锁定重提，先完整回读或以契约明确的安全方式核对结果，经用户需要的确认后解锁；不自动重发。
- 列表读取失败保留旧状态并显示错误，不能伪装成空列表。按打开、前台、成功写入或手动刷新的领域规则回读；不为方便展示添加全局轮询、第二 SSE 或兼容旧字段。
- 工具卡、审批和活动只消费服务端实际投影，不推断隐藏详情、审批状态或保存成功；未知工具可展开，但不能伪造结构化结果。
- 连接与鉴权只保存服务地址和 Session Token，不持久化明文 AccessKey；换服、重连或退出不能泄露或复用错误凭据。测试使用专用智能体/数据，收口后按授权清理。
- 连接页只有地址、临时访问密钥、“测试连接”和“保存”两个主按钮；保存可直接发起当前草稿的连接校验，测试成功只提示“连接正常”，保存后才生效。修改地址或密钥会废弃旧测试证明，新密钥必须重新认证；同址空密钥可沿用已保存的登录状态。探测可取消且可直接关闭，迟到结果不更新草稿；仅真实存储或清理关键阶段锁关闭。换服或旧配置读取异常须先明确确认清除本地业务缓存和旧凭据，不删除远端数据；清理失败保留恢复入口。客户端不提供浏览器地址设置，也不提供只保存地址、稍后认证的路径。

## Expo 与依赖

- 写任何 Expo 或 React Native API 前，先读当前 `package.json` 的准确版本，再查该 SDK 版本对应的 Expo 官方文档；不确定的 API 不凭训练记忆编码。当前项目使用 npm。
- 当前 Expo 58 配套 React 19.3.0、React Native 0.88.1 与 TypeScript 6.0.x；Reanimated、Worklets、WebView 和安全区模块也按 SDK 配套，不独立强升。ESLint 使用 9.x，因为 Expo 配置中的 React/import 插件尚不支持 ESLint 10；升级前重新核对实际 peer 范围，不用 `--force`、忽略检查或运行时修改第三方配置来掩盖冲突。
- 新增依赖前先确认需求无法由现有依赖或推荐 Expo 模块满足；含原生能力的包使用 `npx expo install <package>` 解析 SDK 兼容版本，不用其他包管理器直接安装。
- 本项目采用 CNG：`ios/` 与 `android/` 不入库。目录不存在时不得手工创建或修改，原生行为通过 `app.json` 与 config plugin 配置；发布流程由 [Android 发布指南](android-release-guide.md)管理。
- Expo Go 只含内置原生模块。新增原生能力后需要开发构建或按发布流程重新生成原生工程验证；Expo Web 只能做快速布局检查，不能替代 Android 原生链路。
- 移动优先：触控目标、键盘、安全区、读屏、窄屏和前后台生命周期是常规检查；不为桌面或 Web 预览牺牲原生行为。

## 验证

- 默认本地门禁：`npm run lint`、`npm run typecheck`、`npm test`。这些测试使用本地协议与状态夹具，不能替代真实验收。
- 功能收口前，由主 Agent 启动当前源码的本地隔离真实后端，实际客户端消费相关 HTTP/SSE 并真实调用外部模型；同时在 Android 模拟器或真机验证本轮界面与业务链路。费用授权与数据边界见根规则。
- 涉及主题时按 [主题维护](themes.md) 覆盖三主题、窄屏和真实原生场景；涉及用户可见行为时同步产品手册；涉及 APK 更新、签名或发布时转入 Android 发布指南。
- 文档-only 任务只检查差异、引用、命名与规则一致性；不得为文档修改启动业务、模型或原生验收。

## 智能体文件与原文编辑

- `AgentPage` 共用既有 Agent 的成员主页与智能体设置呈现，组织私有文件、专属规则、技能、维护与动态；发消息和新闻阅读只在主页显示。规则仍用专用 API，不复制指令文件。Feature 设置在对应新闻/短信成员主页或智能体设置，后台采集继续走专用 facade；全局设置不放成员专属配置。`src/group/` 单独持有群聊草稿、定向目标和流，连接内持续挂载；群聊不是 main 私聊，不合并普通私聊；只读展示服务端从实际承接会话 marker 投影的功能通知。无 `@` 省略目标，由服务端交 main；显式 `@` 只发单一目标，未知目标报错。成员间显式通信保留真实来源头像；群聊右上角为群信息，私聊仍为智能体设置。群 POST 断流先回读，不自动重发；不增加第二条通知流。群聊暂不支持附件或消息反馈。功能通知按时间合入展示，标明来源与实际承接私聊入口；点击不改变群输入目标、不启动模型，不等同于群内通知卡片定向续聊。群所有者隐藏时也订阅现有 runtime 失效与重连版本，发送期间延迟回读至收口，读取失败保留旧快照。
- `SmsProvider` 在连接根层持有独立 `SmsStore`、权限状态与原生监听，切页面或智能体不卸载；短信设置页只控制前台可见时的 5 秒只读刷新，离页/后台停止。静默处理没有聊天失效事件，因此不以群通知推断短信完成；重新打开、前台恢复和成功写入后也回读。读取保留脏偏好草稿与失败前数据，写前废弃旧 GET，结果未明只允许显式核对，不由自动刷新解锁或重跑。专用 API 不传当前聊天 agentId。新闻讨论状态同样按连接保留，成功后按服务端 receipt 切入实际目标；结果未明只允许核对，不自动重发。聊天来源只读 metadata.featureSource，不能从文字推断跨智能体归属。
- `NewsPreferencesStore` 由连接根层持有，新闻偏好卡片只订阅并控制打开/关闭；不让页面局部状态重复持有备注。重开、前台和显式核对保留脏草稿，干净备注才跟随服务端；读取失败保留旧值，保存前取消旧 GET，离页不丢保存回执。结果未明的锁定跨页保留，自动读取不解锁，显式核对后才允许再存。不做自动保存、冲突合并或设备持久化，换连接时销毁草稿、回执与在途请求；只提交明确 notes，不写 learnedNotes。
- `FilesScreen` 分屏呈现目录、原文直编、完整前后预览与确认；目录路径由连接内 FilesStore 持有，详情返回保留列表滚动位置，文件草稿在切智能体前显式处理。
- 智能体与文件子页共用 `AgentHeader`。文本文件打开即为原文编辑器，不渲染 Markdown；路径归入标题副文，元信息及下载、删除归右上角信息菜单。首次实际修改才由 FilesStore 建立草稿，输入节点不重挂载，仅有草稿时出现保存操作；确认页仍展示完整操作对象和前后原文。
- `ui/MarkdownContent` 是无聊天清理的安全原生阅读器；`MessageContent` 仅包装聊天独有的思考标签清理。文件页不使用 MarkdownContent，原文、保存确认和结果未明的回读核对不得应用聊天清理或只展示渲染摘要。
