## 架构现状说明

### 单一 Pi Muse 主聊天与暂缓的专题 UI

- 当前源码中消息 Tab/冷启动直接进入永久 main 主聊天，正常根页保留消息/新闻/设置底栏；Pi Muse 形象静态展示。会话列表、切换与专题新建/改名/删除 UI 已移除，专题交互暂缓，不保留隐藏入口。
- 服务端多会话底座、HTTP 契约及客户端通用 SessionStore/API 保留，不删除既有用户会话、历史或工作区。新闻讨论直接追加可编辑的不可信引用到 main 既有草稿，不自动发送，可返回原文章；非 main 通知续聊明确提示暂不可用，不改投主聊天。文件拍平，Dream 全局化。
- 当前改造的真实后端、外部模型、Android 与 `/docs` 渲染证据由主会话验收，不能以本地 fixture 代替，也不代表已发布。

### 工作区状态同步与事件驱动架构
- **前台通知流已接入**：客户端已全面接入 `/api/events` 单长连接通知流（`RuntimeProvider`）。首帧 `ready` 给出运行状态、待审批及活跃工作集合；增量事件实时更新运行状态、待审批、审批决议回执与活动概览；定时任务复用运行事件作为失效驱动并按需回读。
- **全局快照不再盲轮询**：工作区状态复用唯一通知流。短信静默处理没有聊天失效事件，因此短信设置页仅在可见且应用前台时每 5 秒读取开关、偏好和最近条目，离页或后台停止；不增加全局轮询或第二条通知流。
- **独立资源与快照解耦**：定时任务（`/api/jobs`）、长期目标（`/api/goals`）、监控（`/api/monitors`）与记忆（`/api/memories`）均已迁移至独立 REST 端点并支持按需回读与核对，工作区快照仅保留权威身份（identity）。

## 💡 需求与演进事项池

### 连接面板 320dp 窄屏不可滚动，保存按钮被挤出屏幕

- **状态**：`[待排期 / 准备实施]`
- **背景与现状**（2026-11-06，REQ-019 窄屏补验时发现）：
  - 320dp 宽度下打开「服务器连接」面板，一旦出现连接错误文案和/或换服「保存前请确认」块，测试连接/保存/确认清理按钮被推出屏幕；面板内容不滚动，无法在窄屏完成保存或换服（本轮只能在 840x2400 高屏完成操作）。
  - 软键盘弹出时输入栏可上移，但收起键盘后按钮仍在折叠线以下；无障碍 bounds 在动画态出现倒置，定位按钮需以键盘收起后的稳定 dump 为准。
- **演进考量与备忘**：
  - 修复时检查 ConnectionPanel 的滚动容器与 KeyboardAvoidingView 行为，覆盖「有错误文案 + 有确认块 + 键盘开/关」四种组合的 320dp 断言；属既有页面缺陷，与 REQ-019 无关。

### 1. 系统级远程通知（Android 后台 / 锁屏通知）

- **状态**：`[待定 / 暂缓]`
- **背景与现状**：
  - 当前客户端在 App 处于前台时维持 `/api/events` 单长连接；当用户切入后台或锁屏时，主动切断连接彻底休眠以节省系统电量与网络资源。
  - 当用户重新切回前台时，客户端自动恢复订阅并触发必要的状态同步核对。
  - 若服务端长任务在 App 处于后台期间执行完毕或产生待审批，当前客户端不会在手机锁屏或系统通知栏展示系统级推送弹窗。
- **演进考量与备忘**：
  - 若未来需要实现后台唤醒或锁屏推送提醒，Android 优先评估 FCM；iOS 不属于当前默认验收平台，只有在明确恢复 iOS 支持时再纳入方案。
  - 本项目为个人自用，遵循简单优先原则，当前回到前台秒级对账已满足日常使用，此事项暂缓实施，待未来有明确远程提醒需求时再行评估。

### 2. 更完整历史窗口与统一深度分页

- **状态**：`[待定 / 暂缓]`
- **背景与现状**：
  - 当前只读活动历史（`/api/activities`）与审批历史（`/api/approvals`）均已实现基于 cursor 游标的增量分页，用户滚动到底部按需加载，内存无膨胀。
- **演进考量与备忘**：
  - 未来若数据积累达到更长时间跨度且需要跨会话深层冷归档回溯窗口，可进一步评估统一的跨领域游标分页规范。
  - 当前各领域独立游标分页稳定可靠，暂无进一步增加复杂度的必要。
