# 主题维护

主题功能集中在 `src/theme/`，不依赖服务器、凭据或业务 Store。应用根级只有一个 `ThemeProvider`；页面消费语义颜色，不自行推断配色。导航与键盘边界见[移动开发指南](mobile-development-guide.md)。

## 当前主题

| ID | 名称 | 明暗模式 | 说明 |
| --- | --- | --- | --- |
| `classic` | 经典蓝白 | `light` | 默认白底、冷灰、深色文字与蓝色强调 |
| `light` | 晨光白 | `light` | 暖白、柔和灰绿色表面 |
| `dark` | 深夜黑 | `dark` | 深色画布与低调蓝光 |

经典蓝白保留原画布、表面、控件、选中态、正文、次级文字、分隔线及头像底色。文字与动作按钮的对比度按现有主题回归检查，不通过恢复旧页面或演示数据来恢复配色。

## 修改配色与共享几何

- 每套配色独立放在 `src/theme/presets/`；改某套颜色只修改对应文件。
- 每套配色实现 `types.ts` 的完整 `ThemeColors`。组件不得直接引用 preset 或写固定色值，尤其不能把浅色背景与深色正文混用。
- `blue` 与 `onAccent` 配对用于动作和用户气泡；小字强调用 `accentText`；状态色配各自 `Soft` 背景。
- 字号、圆角、间距和控件命中区来自 `src/theme/tokens.ts`。`src/ui/tokens.ts` 是现有组件的兼容入口，不维护另一套配色。
- `SettingsHome` 使用分组卡片和统一图标列表行，文字允许换行、箭头不收缩。不能把大量独立 `ActionButton` 或整个主题选择器重新堆进首页。
- 常规文字操作用 `ActionButton`，选择用 `ChoiceChip`，输入用受控 `FormInput`，表面用 `Card`；保存资格、未明锁、完整文件预览与审批仍由业务页面和 Store 决定。
- 消息根页人物透明、64dp、顶部居中；不使用 enclosing 大卡、圆头像底座或 8 向 tint 副本描边。紧贴人物的短状态胶囊用 `floatingSurface` / `floatingLine`，文字用 `ink`，同一至少 48dp 入口持有完整状态无障碍标签。状态来自 `mainProgressLabel` 的真实运行事实，空闲克制显示「就绪」，断线不把旧缓存当空闲。长文胶囊上限 220dp，窄窗口继续收缩，单行省略但不截断读屏标签，状态行随字体增高；纯 `companion-layout.ts` 同时为聊天提供随内容滚走的起排 padding。
- 原位展开态使用当前主题 `panelVeil` 中性柔和全屏表面，不声称 blur；表面从同一人物中心在 280ms 内展开，内容轻微渐现，人物和状态不交叉淡入、不移走或重挂。关闭反向、快速开关可反转，减弱动效立即到位。展开和关闭动画期间隔离下层触控/读屏；更高优先级原生 Modal 仍在其上。主题变化只更新语义色，不改变连接/聊天/形象 key。
- 一级底栏只在消息、新闻、设置根页显示；键盘或覆盖层（含形象关闭动画）打开时隐藏，文章和设置子页不显示底栏。新闻与设置隐藏 compact，键盘显隐不改变人物顶部锚点。新闻「返回文章」使用左上角独立的 48dp `IconControl` 箭头，展开时暂隐；固定命中区不受字体增大影响，也不把额外一行盖到短对话上。

## 增加主题

1. 在 `presets/` 新建 ASCII 文件名的 `.ts` 文件，导出符合 `ThemeDefinition` 的定义。
2. 在 `registry.ts` 注册；主题身份由 `id` 表达，`appearance` 只表示明暗，不能互换。
3. 更新注册表、颜色与偏好回归，完成实际 Android 渲染验证。若增加复杂快捷策略，只改主题层，不在业务页面散布主题分支。

## 切换与保存

- 入口是「设置 → 应用 → 外观主题」。首页只有入口行，`ThemePicker` 在独立二级页面显示色板、单选标记、本机恢复/保存状态和错误。
- 未连接服务器时也可以选择外观；需要服务端的设置入口引导连接，不伪造空业务数据。
- `useTheme()` 提供 `themeId`、`theme`、`appearance`、`colors`、`selectTheme()` 与 `toggleAppearance()`。按主题 ID 判断选中，不按明暗模式判断。
- 主题独立保存在设备，不保存或上报地址、Token、正文。切换立即生效，写盘串行；旧恢复读取或旧写入错误不能覆盖新选择，损坏偏好回到经典蓝白。
- 亮暗快捷行为记住上次选择的浅色主题；不自动跟随系统明暗。
- 不按主题更换连接、业务 Provider、面板根层或聊天 React key，不因此断开 SSE、清草稿或解除未明锁。冷启动恢复主题，不承诺跨进程保存未发送草稿。
- 原生根页与独立 Modal 使用 `ThemeStatusBar`；系统减少动画偏好由 `src/ui/use-reduced-motion.ts` 维护。

## 验证

```sh
npm run typecheck
npm run lint
npm test
```

本地夹具不替代原生验收。实际覆盖经典蓝白、晨光白、深夜黑、窄屏、较大系统字体、长标签换行、设置逐级返回、草稿与连接保持。

主题和布局共享代码有变化时，还需核对键盘展开后输入与操作区没有被真实 IME 遮挡，不能只看无障碍树中是否存在输入框。

`tools/e2e-themes*` 是专项工具，可能仍假设旧页面与选择器。运行前查看脚本支持的参数和当前入口；未实际执行的脚本不作为本轮原生通过证据。iOS 与实体手机未运行时分别标明，不用 Expo Web 替代。
